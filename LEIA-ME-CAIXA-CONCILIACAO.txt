BLACKOUT MOTOS — SALDO INICIAL / CONCILIAÇÃO DE CAIXA

O que esta atualização faz
--------------------------
1. Cria a tela:
   /caixa/conciliacao

2. Na tela /caixa aparece um botão fixo:
   "Conciliar Caixa"

3. Primeiro uso:
   - informe a data de início do controle;
   - informe o saldo real no banco;
   - informe dinheiro em espécie;
   - informe outros valores disponíveis.

4. O sistema cria um ponto de partida SEM apagar o histórico:
   - calcula todo o saldo das movimentações antigas;
   - cria um ajuste técnico que neutraliza esse histórico;
   - registra o saldo real informado como "Saldo inicial do caixa";
   - os lançamentos técnicos usam a data 1900-01-01 para não poluir
     os relatórios mensais atuais.

5. A partir daí:
   saldo inicial
   + novas entradas
   - novas saídas
   = saldo calculado atual

6. Conciliação:
   você informa novamente o que existe de verdade no banco/dinheiro/outros.
   O sistema mostra:
   - saldo calculado;
   - saldo real;
   - diferença;
   - histórico das conferências.

7. Gastos históricos:
   app/despesas/nova/page.tsx foi ajustado.
   Se o pagamento for anterior à data de início do controle:
   - o gasto continua salvo;
   - continua entrando no custo da moto;
   - mas NÃO cria nova saída no caixa atual.

IMPORTANTE
----------
Não cadastre saldo inicial como uma entrada manual no Caixa.
Use somente a tela /caixa/conciliacao.
