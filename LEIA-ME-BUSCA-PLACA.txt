BLACKOUT MOTOS — Busca de placa RegCheck / Brasil

Arquivos alterados/adicionados:
- app/motos/nova/page.tsx
- app/api/veiculos/buscar-placa/route.ts
- REGCHECK-ENV-EXEMPLO.txt

O que foi implementado:
- botão "Buscar placa" no cadastro da moto;
- a consulta só acontece quando o botão é clicado (não gasta crédito ao digitar);
- a credencial fica somente no servidor;
- preenche automaticamente marca, modelo, ano, cor, chassi e cilindrada quando a API retornar esses dados;
- RENAVAM continua manual porque a documentação brasileira fornecida não documenta esse campo;
- nenhuma alteração SQL é necessária.

CONFIGURAÇÃO LOCAL
1. Abra .env.local.
2. Adicione:
   REGCHECK_USERNAME=SEU_USUARIO_REGCHECK

Opcional:
   REGCHECK_ENDPOINT=https://www.placaapi.com/api/reg.asmx/CheckBrazil

3. Não use NEXT_PUBLIC_ no nome da variável.
4. Reinicie npm.cmd run dev depois de alterar o .env.local.

TESTE
A documentação fornecida informa a placa brasileira de teste:
KNX9595

VERCEL
Cadastre REGCHECK_USERNAME também nas Environment Variables do projeto no Vercel.
Depois gere um novo deploy.

IMPORTANTE
O endpoint foi montado conforme a documentação fornecida:
CheckBrazil + RegistrationNumber + username.
Se a conta do provedor usar um host diferente, altere somente REGCHECK_ENDPOINT.
