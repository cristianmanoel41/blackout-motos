BLACKOUT MOTOS
ADICIONAR CAPACETE A UMA VENDA JÁ CONCLUÍDA

O que foi criado
----------------
1. Ao abrir uma venda em /vendas/[id], aparece um botão fixo
   "Adicionar capacete".
2. O botão abre /vendas/[id]/capacete.
3. Você informa valor, data e forma de pagamento.
4. Depois escolhe uma das duas situações:

   A) "Sim, já estava incluído"
      - vincula o valor do capacete à venda;
      - NÃO cria nova entrada no caixa;
      - NÃO aumenta novamente o valor da venda;
      - evita dinheiro duplicado.

   B) "Não, foi recebido depois"
      - vincula o valor do capacete à venda;
      - cria uma NOVA entrada no caixa;
      - use somente quando esse dinheiro realmente ainda não
        estava lançado.

5. A tela mostra o histórico de capacetes vinculados.
6. É possível excluir um lançamento errado.
   Se ele criou uma entrada no caixa, a entrada é removida junto.

Importante
----------
Esta função é para os capacetes antigos/sem cadastro de estoque.
Ela não mexe no estoque atual de helmet_models.

SQL
---
Execute UMA VEZ no SQL Editor:
supabase/capacete_venda_concluida.sql

Esse SQL também cria a tabela caso o SQL do recurso anterior
de "capacete sem cadastro" ainda não tenha sido executado.

Arquivos adicionados
--------------------
app/vendas/[id]/layout.tsx
app/vendas/[id]/VendaAcoesFixas.tsx
app/vendas/[id]/capacete/page.tsx
app/api/vendas/[id]/capacetes/route.ts
supabase/capacete_venda_concluida.sql

Este pacote NÃO substitui app/vendas/[id]/page.tsx.
Assim, a sua tela atual de editar/ver venda permanece intacta.

Instalação
----------
Expand-Archive "$env:USERPROFILE\Downloads\adicionar_capacete_venda_concluida_blackout_pronto.zip" -DestinationPath "." -Force

Depois execute o SQL e teste:

Remove-Item -Recurse -Force .next -ErrorAction SilentlyContinue
npm.cmd run build
