CORRECAO DO TOTAL DO ESTOQUE - BLACKOUT MOTOS

O QUE FOI CORRIGIDO

- A tela de Estoque agora abre com o filtro "Disponivel" selecionado.
- O total e os botoes por cilindrada contam somente as motos disponiveis por padrao.
- O total inicial do Estoque passa a acompanhar o numero "Motos disponiveis" do Dashboard.
- As motos vendidas continuam cadastradas e podem ser consultadas escolhendo "Status: Todos" ou "Vendida".
- O botao "Limpar filtros" volta para a visualizacao de motos disponiveis.

COMO INSTALAR

1. Extraia este ZIP na raiz do projeto:

   C:\Users\zlYoungthug\orca\blackout-motos

2. Confirme a substituicao do arquivo quando o Windows perguntar.

3. No PowerShell, dentro da pasta do projeto, execute:

   Remove-Item -Recurse -Force .next -ErrorAction SilentlyContinue
   npm.cmd run build

4. Se o build terminar corretamente, salve e envie:

   git add app/estoque/page.tsx
   git commit -m "Alinha total do estoque com motos disponiveis"
   git push origin main

Nenhuma alteracao no banco de dados e necessaria.
